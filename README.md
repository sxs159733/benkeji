**在线浏览：** https://sxs159733.github.io/benkeji/

- 四年时间线：从军训到毕业典礼
- 课程档案：八个学期、170 学分的课程与成绩
- 教材书架：41 本课程教材，含夸克网盘中留存的 17 本真实课本
- 竞赛、荣誉与奖学金，19 张证书影印
- 校园光影：26 个瞬间

## 技术

```bash
npx serve .
```
